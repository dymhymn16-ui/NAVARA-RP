# MihanRP - Advanced Roleplay Gamemode for SA-MP

MihanRP is a comprehensive roleplay gamemode for San Andreas Multiplayer (SA-MP) that has been developed over the course of more than one year. This project brings an immersive roleplay experience with extensive features, custom systems, and a complete framework for server management. The gamemode was created by Abolfazl Hosseini and is now available to the public.

The server language is Persian (Finglish), and the gamemode was designed for the MihanRP server project.

---

## Key Features

### Factions System (15+ Factions)

The gamemode includes more than 15 unique factions, each with specific roles and systems:

- **Police Department** - Present in all 3 cities (Los Santos, San Fierro, Las Venturas)
- **Medical/EMS** - Present in all 3 cities
- **Gang Factions** - Complete gang system with:
  - War system
  - Drug planting system
  - Army robbery system
- **Mafia Factions** - Complete mafia system with:
  - Business war system
  - Drug planting system
  - Army robbery system
- **Municipality** - Presidential election system
- **Bank Faction**
- **NOPO Faction**
- And many more...

### Core Systems

#### Housing System

- Advanced gate system for houses
- Custom house mapping with high-quality interiors

#### Inventory & Player Systems

- Complete inventory system
- Accessory system with 256+ accessories
- Advanced DM zone system with 5 custom maps
- Training system for teaching players the gameplay mechanics
- Advanced lobby system for Derby and Parkour events
- User-customizable lobby creation system

#### Vehicle & Customization

- Vehicle accessory system
- 25+ fully customized vehicles

#### Administration & Server Control

- Advanced admin system with complete server control
- Connection management tools
- Full server logging system

#### Anti-Cheat

- Advanced anti-cheat system detecting 56+ cheat types

#### Communication

- Voice chat system integration

#### NPC & Visual Systems

- Fake player system for server population simulation

## Project Structure

- **gamemodes/new.pwn** - Main entry point of the project
- **pawno/pawno.exe** - Compiler executable for building the project
- **screenshots/** - Screenshots folder for previewing the gamemode features
- **mihanrp.sql** - Database file for the project

---

## Compilation Instructions

To compile the project:

1. Navigate to the `pawno` folder
2. Run the `pawno.exe` executable
3. Open the `new.pwn` file within Pawno
4. Use the compile option to build the gamemode

---

## Database Setup

The `mihanrp.sql` file contains the complete database structure required for the gamemode. Import this file into your SQL database management system (such as phpMyAdmin or MySQL command line) to set up the necessary tables and data for the server.

## Getting Started

1. Clone or download this repository
2. Import the `mihanrp.sql` file into your SQL database
3. Place the gamemode files in your SA-MP server's `gamemodes` directory
4. Compile the `new.pwn` file using Pawno (located in the `pawno` folder)
5. Configure your server configuration file (server.cfg) to load the compiled gamemode and connect to your database
6. Start your SA-MP server
